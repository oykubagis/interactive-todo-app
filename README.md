# Interactive Todo List Application

A functional and lightweight task management web application that allows users to create, track, and manage daily tasks efficiently.

## About The Project

This project is a task management system designed to help users stay organized. It demonstrates fundamental frontend concepts including DOM manipulation, event handling, and modern UI design.

## Features

- Dynamic Task Management: Add new tasks and remove completed ones instantly.
- Task Status Tracking: Mark tasks as completed with a single click.
- Clean Interface: User-friendly and minimalist layout.

## Built With

- HTML5
- CSS3
- JavaScript
